
# 🎬 Churn Decoded: Netflix Subscriber Analytics

## 📌 Project Overview
This project analyzes Netflix subscriber data to explore customer behavior and identify patterns associated with churn. Python is used for data cleaning and analysis, while Power BI is used to create an interactive dashboard.

## 🎯 Objectives
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Analyze subscriber churn patterns.
- Create an interactive Power BI dashboard.
- Present useful insights for customer retention.

## 🛠️ Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Power BI
- Jupyter Notebook / Google Colab

## 🔍 Project Workflow
1. Data inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. Dashboard creation
5. Insights and conclusions

## 💡 Key Finding
Support ticket volume emerged as an important pattern associated with churn in the analyzed dataset.

*Note: This finding describes an association in the analyzed data, not proof of causation.*
